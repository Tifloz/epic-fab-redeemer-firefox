# Changelog

## 0.1.4

- Recognize current French Epic giveaways on product pages with a separate base game purchase panel.
- Pause at the French Epic checkout and check the product for ownership when the user resumes.

## 0.1.3

- Recognize French limited-time Fab offers and their visible promotional prices.
- Open Fab offers without mistaking footer links for a license prompt.
- Explain when a Fab offer requires the user to complete checkout.

## 0.1.0

- Initial Firefox desktop implementation for Epic free PC giveaways and Fab free assets.
- Added local settings, sequential processing, status reporting, and manual pause/resume handling.
- Recognizes French Epic giveaway headings and visible free-until deadlines.
- Added a stable Firefox Gecko add-on ID for signed distribution.
- Live storefront claim flows have not yet been validated.
